# เอกสารกำหนดขอบเขตโครงการ (Scope Specification)

## ระบบนี้ทำอะไร
ระบบร้านขายหนังสือและอีบุ๊กออนไลน์ (E-Book Store) ลูกค้าค้นหาและสั่งซื้อ ชำระเงินแบบจำลอง
แล้วได้ลิงก์ดาวน์โหลดเมื่อคำสั่งซื้อยืนยันแล้ว พร้อมทั้งมีผู้ช่วยปัญญาประดิษฐ์แนะนำหนังสือตามความต้องการ

## กลุ่มผู้ใช้
- ลูกค้า / นักอ่าน (Customer)
- ผู้ดูแลร้าน (Store Administrator)

## อยู่ในขอบเขต
- ระบบสมาชิกและบทบาท (Customer, Admin)
- รายการหนังสือและแคตตาล็อก E-Book
- ค้นหาและกรองตามหมวดหมู่
- ตะกร้าสินค้าและการคำนวณราคา
- คำสั่งซื้อและระบบชำระเงินจำลอง (Slip Upload)
- ส่วนผู้ดูแลร้าน (Admin Backoffice) ตรวจสอบและอนุมัติคำสั่งซื้อ
- ผู้ช่วยปัญญาประดิษฐ์แนะนำหนังสือ (AI Bookstore Assistant) พร้อม Fallback
- รายงานสถิติยอดขาย 4 มิติ และการส่งออก CSV (UTF-8 BOM)

## อยู่นอกขอบเขต
- การตัดบัตรเครดิตผ่าน Payment Gateway ของธนาคารจริง
- การจัดเก็บไฟล์หนังสือจริงขนาดใหญ่ระดับเทระไบต์
- ระบบป้องกันการคัดลอกไฟล์ระดับฮาร์ดแวร์ (Hardware DRM)
- การแจ้งเตือนทาง SMS หรืออีเมลจริงภายนอก
- ระบบคะแนนสะสมและระบบคูปองส่วนลดซับซ้อน

## กติกาของลิงก์ดาวน์โหลด
**ลิงก์ดาวน์โหลดเปิดได้เฉพาะหนังสือที่อยู่ในคำสั่งซื้อที่ยืนยันแล้ว และเป็นคำสั่งซื้อของผู้ใช้คนนั้นเอง**

## สิ่งที่ตัดสินแล้ว
1. คำสั่งซื้อมีสามสถานะ คือ รอชำระ (`pending`), ยืนยันแล้ว (`confirmed`), และ ยกเลิก (`cancelled`) และเปลี่ยนจากรอชำระไปยืนยันแล้วได้ทางเดียว
2. รายการในคำสั่งซื้อเก็บราคา ณ เวลาที่ซื้อ (`price_at_purchase`) ไม่ได้ดึงราคาปัจจุบันของหนังสือ (Snapshot Price เพื่อรักษาความถูกต้องของ 3NF)
3. หนังสือที่ถูกปิดการขาย (`is_active = FALSE`) ลูกค้าที่เคยซื้อไปแล้วในคำสั่งซื้อที่ยืนยันแล้วยังคงดาวน์โหลดได้ตลอดไป
